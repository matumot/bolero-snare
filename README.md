
# ボレロ スネア（Boléro Snare）

ラヴェル《ボレロ》のスネアドラム・オスティナート（3拍子・2小節）をブラウザ内で合成音として再生する、オーケストラ練習用のWebアプリです。

Web Audio APIを使用しており、専用サーバーや音源ファイルは不要です。HTMLファイル1枚で動作します。

## Webアプリ

### ▶ [ボレロ スネアを起動する](https://matumot.github.io/bolero-snare/)

PC・スマートフォンのブラウザから利用できます。インストールは不要です。

## 主な機能

- **TEMPO**：40〜120 BPM（原曲指定 ♩=72）
- **VOLUME**：音量調整
- **TONE**：タイト（乾いた音）〜ディープ（太い音）
- **カウントイン**：1小節カウントしてから再生開始
- **自動クレッシェンド**：pp → ff（10〜17分）
- **Wake Lock**：再生中の画面消灯を防止（対応ブラウザのみ）
- スマートフォンのタッチ操作に対応

## 使い方

1. [Webアプリ](https://matumot.github.io/bolero-snare/)を開きます。
2. TEMPO、VOLUME、TONEを調整します。
3. 再生を開始します。
4. 1小節のカウントイン後、スネアドラムの演奏が始まります。

## 注意

- iPhoneでは、マナーモード（サイレントスイッチ）やブラウザの設定によって音が出ない場合があります。
- Wake Lock機能は対応ブラウザでのみ動作します。
