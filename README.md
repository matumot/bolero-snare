# ボレロ スネア

ラヴェル《ボレロ》のスネアドラム・オスティナート（3拍子・2小節）をブラウザ内で合成音として再生する、オーケストラ練習用のWebアプリです。サーバー不要の1枚のHTMLで動きます。

- TEMPO ノブ：40〜120 BPM（原曲指定 ♩=72）
- VOLUME ノブ
- TONE ノブ：タイト（乾いた音）〜ディープ（太い音）
- 1小節カウントしてから開始、自動クレッシェンド（pp→ff、10〜17分）
- 再生中は画面を消灯しない（Wake Lock 対応ブラウザ）

## 注意

iPhone はマナーモード（サイレントスイッチ）だと音が出ないことがあります。
